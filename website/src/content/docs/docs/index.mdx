easy-auth is a Rust authentication library and server built with **Axum and PostgreSQL**. It handles sign-in, user identities and server-side sessions. Your application defines what an authenticated user can do.

You can run it as a standalone process for a same-origin browser app, or embed its router into an existing Axum service. Both use the same authentication core and database transactions.

<Aside type="note" title="Project status">
  This is pre-release software. Use the repository source while crate names and
  APIs are unpublished. Check the feature status before choosing a provider.
  SAML's maintainer-directed activation is not an independent security approval.
</Aside>

## Choose how to run it

|                         | Standalone server                               | Embedded Axum                                      |
| ----------------------- | ----------------------------------------------- | -------------------------------------------------- |
| Start command           | `cargo run -p easy-auth-server --bin easy-auth` | `cargo run -p easy-auth-server --example embedded` |
| HTTP process            | The included server                             | Your application                                   |
| Core policy and storage | Shared Rust core and PostgreSQL                 | The same core and PostgreSQL                       |
| Best starting point     | Try the reference browser flow                  | Add authentication beside application routes       |

Standalone mode is intended for same-origin browser applications. Do not share its cookies across unrelated applications or treat an external provider token as an easy-auth session.
