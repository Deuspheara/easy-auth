# Security policy

This is experimental alpha authentication software, not production identity infrastructure. No independent security audit or protocol certification has been completed. Only features with recorded tests are implemented; SAML and interoperable OIDC issuer support are release gates.

Do not disclose exploitable details or secrets in public issues. Once a public repository is provisioned, use its GitHub Security tab → Report a vulnerability if private reporting is enabled. Until a verified private reporting channel is published, do not send sensitive reports through public channels. A maintainer contact and response policy must be established before accepting production adoption.

See docs/security/threat-model.md and docs/research/protocol-dependencies.md. Maintainers must privately reproduce reports, prepare tests and fixes, review affected versions/dependencies, coordinate disclosure, and publish an advisory when appropriate. No response-time guarantee is claimed during initial setup.
