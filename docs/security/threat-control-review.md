# Threat control review — AUTH-47

Recorded 2026-10-26. Internal source/assertion review of the fifteen threats in the
[threat model](threat-model.md), with execution evidence in the
[protocol validation matrix](protocol-validation-matrix.md). This maps specific
controls and assertions; it is not independent security approval, exhaustive
attack coverage, protocol certification or production acceptance.

## Source and execution scope

The review starts at `4975e06ab165e3c09f42b32d5ac0164699da1cc2`. Its authentication
implementation is identical to runtime baseline
`b4638a6706c81c1be2245108c190b48c31637895`; the intervening commit changes CI and
documentation only. The recorded full workspace run includes 651 real PostgreSQL
cases, HTTP/core/standalone tests and no ignored cases. Current owned browser,
provider, dependency qualification and configuration receipts retain their own
profile and source/binary hashes. Counts across profiles overlap.

For each row, inspect the actual control and its refusal/valid/rollback assertions;
a test name or directory is not execution proof. PostgreSQL tests may arrange
explicit deadlines or transaction gates to observe atomicity; browser tests must
obtain authority through genuine public flows. Controlled offline provider ports,
ordinary signed fixtures and actual owned Keycloak have different evidence scope.
No new XML/signature fixture, custom cryptography, fuzz, load or signature-concurrency
experiment is introduced by this review.

## Findings and remaining acceptance

Corrected documentation drift: universal Origin/8 KiB wording, generic S256
wording that obscured Apple's fixed profile, obsolete unconditional SAML blocking,
and outdated twenty-case passkey evidence. Current exceptions are explicit
composition boundaries, not permissive fallbacks. Authentication behavior, policy,
migrations, dependencies and security assertions are unchanged.

Every listed threat now has a bounded source/assertion mapping. Coverage totals
and these inspected controls do not prove absence of vulnerabilities. Registered
Google/Apple manual/native/OS/device checks remain deferred and unpassed. Independent
review remains absent; the SAML waiver and outbound OIDC hard release gate keep
their existing scope. Backup/restore/migration recovery, key custody/rotation,
capacity and publication are separate tracked acceptance. AUTH-47 remains In
Progress until its remaining acceptance has evidence; no unavailable check is
counted as a pass.
