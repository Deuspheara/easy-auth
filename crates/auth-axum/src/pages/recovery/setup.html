Account recovery

A recovery code helps you get back into your account if you lose access to all your passkeys. Save it now while you can still sign in. If you need it later, use it with your account ID to request a replacement passkey; recovery includes a waiting period.

This reference client is experimental. Recovery policy and device support still require independent review before ordinary activation.

Keep multiple working passkeys when possible. A saved code is a bearer secret: anyone who steals it can request recovery. It is not phishing resistant. Save it offline, separately from your passkeys. Confirmation cannot prove you retained an offline copy.
